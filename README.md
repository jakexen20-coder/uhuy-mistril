# Mistral Large 3 Chatbot

A powerful AI Chatbot built with Next.js, powered by Mistral Large 3.

## Features
- **AI Chat**: Conversational interface with Mistral Large 3.
- **Vision**: Upload images for analysis.
- **Coding & Translation**: Specialized modes.
- **History**: Saves chats locally.
- **Monetization**: AdSense placeholders ready.
- **Multilingual**: Indonesian and English support.

1.  Clone repo
2.  `npm install`
3.  `npm run dev`
